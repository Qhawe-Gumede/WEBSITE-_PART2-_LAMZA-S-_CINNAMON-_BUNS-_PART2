 Lamza's Cinnamon Buns & Desserts

Lamza's Cinnamon Buns & Desserts is a welcoming dessert website created to showcase freshly baked cinnamon buns, sweet treats, and ways for customers to explore the bakery's offerings online.

 About the Website

The website is designed to give visitors a simple, appetising introduction to Lamza's desserts. It presents the brand, highlights featured products, and makes it easy for customers to browse the menu and get in touch.
 Part 2 Update

Part 2 expands the website into a more complete customer experience. The updated site focuses on clearer navigation, stronger visual presentation of the desserts, and improved access to key information.

Key additions and improvements include:

- A refined home page that introduces the Lamza's brand.
- Product and dessert sections for showcasing available treats.
- Clearer menu content and product descriptions.
- Improved navigation between pages and sections.
- Contact and ordering information for customers.
- A responsive layout that works across desktop and mobile devices.
- Improved styling, spacing, colours, and imagery to create a warm bakery-inspired look.

 Main Features

Technologies Used

Part 2 Update

This website is built using standard front-end web technologies:

- HTML for page structure
- CSS for layout, colours, typography, and responsive styling
  

 Running the Website

1. Download or clone the project files.
2. Open the project folder.
3. Open `index.html` in a web browser.

If the project uses a local development server, start that server before opening the website in your browser.
